Skill completeness

Tick a box only when that line is already on the resume. An empty box means the line is still missing. This sheet has no score, no XP, and no points. A blank is a note, not a penalty.

Original worksheet. Fill it by hand. Nothing here is a checkout, a game, or a mastery tree.

Contact

  • Name is on the file, spelled the way I want a hiring person to say it.
  • Email is one I actually read.
  • Phone is present only if I want calls. Otherwise the box stays empty on purpose.
  • City or region is enough. Street address stays off.
  • A profile or portfolio link is listed only if I own it and it opens.
