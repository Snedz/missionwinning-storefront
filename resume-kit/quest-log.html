Resume Kit

Quest log

Do these in order. Skip none. There is no timer.

  1. Base resume. One master doc. Standard headings. No graphics in the ATS copy.
  2. Target. Pick one role. Copy 8–12 real phrases from that posting.
  3. Tailor. Mirror those phrases only where they are true.
  4. Cover note. Four sentences: why this role, one proof, one ask.
  5. Send. Apply once. Save the confirmation.
  6. Follow-up. One polite note after 7 days if you have not heard back. Then stop.
