How to tailor a resume to a job posting

Updated 2026-09-17 · Answer-shaped page for Google/ChatGPT citations. No “guaranteed interviews.”

  1. Paste the job description into a blank doc (kit includes a worksheet).
  2. Highlight 5–8 must-haves (skills, domain, scope, tools).
  3. For each must-have, write one evidence line from your real work — or leave blank (do not invent).
  4. Reorder bullets so the strongest matches for this role sit first under each job.
  5. Mirror the posting’s language only where it is true for you.
  6. Run the honesty checklist. Export. Submit.
