Use one useful portfolio link

Place a short, readable URL beside your name or in a dedicated links line. The destination should show work you can discuss and should not require a recruiter to request access.

  1. Choose two to four relevant examples, not every artifact.
  2. Add a one-sentence context note for each example: role, contribution, and result you can defend.
  3. Open the link in a private window and check mobile readability before sending the resume.

If the work is confidential, describe the process without exposing private data. A portfolio link supports your evidence; it cannot replace clear resume bullets.
