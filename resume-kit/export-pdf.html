Export the ATS markdown to PDF

Use the Markdown resume as the source, then export a clean PDF locally. Keep the document simple so applicant-tracking systems and people can read it.

Google Docs

  1. Open a new Google Doc and paste the ATS markdown as plain text, or render it first in a Markdown editor.
  2. Use a standard font such as Arial, Calibri, Georgia, or Times New Roman at a readable size.
  3. Use normal paragraphs and headings. Do not use text boxes, columns, tables for layout, icons, or decorative graphics.
  4. Check the page breaks, dates, links, and spelling.
  5. Select File → Download → PDF Document (.pdf).

Microsoft Word

  1. Paste the ATS markdown as plain text into a new Word document.
  2. Choose a standard font such as Arial, Calibri, Georgia, or Times New Roman.
  3. Keep one column with ordinary paragraphs and headings. Do not use text boxes or layout tables.
  4. Review the exported pages and confirm the contact details and dates are accurate.
  5. Select File → Save As, choose PDF, and save.

Final check

Open the PDF after saving, select some text to confirm it is real text, and verify the filename is professional. Never add employers, dates, metrics, or credentials that are not true.
